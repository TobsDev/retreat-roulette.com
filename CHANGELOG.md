# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2025-04-30

### Added
- New slot machine interface with improved animations
- Save functionality for favorite combinations
- Share feature with social media integration
- Sound effects with toggle
- Legal notice modal
- Mobile-responsive design
- End-to-end testing suite
- Continuous Integration with GitHub Actions

### Changed
- Updated word lists for more entertaining combinations
- Improved UI/UX with Tailwind CSS
- Enhanced animations with Framer Motion

### Fixed
- Modal centering issues
- Sound loading delays
- Mobile touch interactions
